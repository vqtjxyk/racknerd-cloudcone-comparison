## 机房与线路：这是 RackNerd 赢面最大的地方

选机房时记住一条规则：面向中国大陆的访问，两家都只看西海岸节点，其他机房不用考虑。

RackNerd 有 21 个数据中心可选，但国内用户的优先级很明确：首选洛杉矶 DC03 和洛杉矶 DC02（2GB 及以上套餐可选），次选圣何塞、西雅图，延迟通常在 150ms 出头；欧洲的阿姆斯特丹、法国节点适合服务欧洲用户的场景。走的是普通国际线路（电信 163、联通 4837、移动 CMI），靠 Noction IRP 做路由优化，明确说一句：这不是 CN2 GIA，晚高峰延迟和速度会有波动，官方也不掩盖这一点。

有个常被忽略的细节：RackNerd 的洛杉矶 DC02 和 CloudCone 用的是同一个 Multacom 机房，所以这两个节点到国内的速度差不多。差别在于 CloudCone 只有这一个选择，而 RackNerd 还有达拉斯、芝加哥、纽约等一堆备选，IP 被墙或者线路抽风时可以删机换机房重开。

流媒体和 AI 服务解锁方面，RackNerd 的 Multacom 机房（洛杉矶 DC02）可以解锁 ChatGPT 和 Netflix 自制剧；ColoCrossing 系的机房能解锁 ChatGPT 但解锁不了 Netflix。洛杉矶节点还有个少见的加分项：25 端口开放，想自建个人邮件服务器的话，同价位里很难找到第二个。IPv6 也是加分项，洛杉矶和法国机房开工单可以免费申请最多 100 个 IPv6 地址，ColoCrossing 机房则只有 IPv4。

## 面板与功能：SolusVM 够用，但 CloudCone 的面板确实更全能

这一项 CloudCone 明显占优，得如实说。

RackNerd 用 SolusVM 面板，功能就是重装系统、开关机重启、VNC 控制台这些基础操作，没有快照和自动备份，数据备份要自己写脚本推到外部存储。新上线的 ctrl 面板补了一部分短板：一键部署应用（Ollama、AnythingLLM、n8n、Coolify、Portainer 等）、入站流量防火墙规则、带宽监控、HTML5 VNC 控制台。想跑 AI 工具的话官方给了明确的内存门槛：n8n 和 Coolify 2GB 内存就够，AnythingLLM、Ollama 这类至少 4GB，所以想折腾本地 AI 的话 4GB 档起步比较稳。所有套餐属于非托管（unmanaged）服务，系统层面的事情自己负责。

CloudCone 的自研面板功能更全：快照、自动备份、防火墙规则、API 接口、按小时计费明细都有，SC2 高级线直接内置自动备份和快照。一个值得写进决策的背景是 2026 年 1 月底 CloudCone 洛杉矶 DC1 遭遇过一次勒索软件式攻击，利用了第三方虚拟化平台的漏洞，密苏里节点未受影响；官方的善后处理算到位（事件报告、受影响客户补偿、迁移自研虚拟化平台），但这也解释了为什么用 CloudCone 的老用户会反复强调：不管套餐带不带备份，自己再做一份异地备份。

磁盘 I/O 方面，各来源数据有出入：有的评测给 RackNerd 部分节点 100–200MB/s 的读数，也有实测记录 KVM 套餐（SSD RAID-10）顺序读写 240–280MB/s，AMD Ryzen 系列走 NVMe 则超过 1GB/s。可以确定的是不同节点、不同系列之间差距不小，介意 I/O 就认准 Ryzen 系列或者直接看机型存储类型。

## 售后、退款和政策：下单前必须知道的四件事

**退款**是两家差距最刺眼的一项。RackNerd 不支持退款，特价套餐尤其明确；CloudCone 早年支持 7 天退款（按小时扣费后退余额），但 2025 年 6 月起政策已改为不退款。也就是说现在两家都是“付款前想清楚”，好在 CloudCone 提供测试 IP，下单前可以先从自己网络 ping 一下线路质量。RackNerd 的规避办法是利用它宽松的换 IP 政策：开通 72 小时内 IP 被墙可以免费换一次，之后每次换 IP 收 $3，控制面板自助操作就行。

**流量翻倍**是 RackNerd 独有的隐藏福利，大部分对比文没讲清楚：在 LowEndTalk 论坛的 "TOP PROVIDER RackNerd LowEndTalk" 帖子下留言、附上订单号，一般 2–3 天后流量翻倍，而且是永久的，续费也按翻倍后的量算。等于花 5TB 的钱拿到 10TB，注册个 LET 账号的功夫就省出来了。

**支付**两家都友好：支付宝、PayPal、信用卡都支持，RackNerd 还接受微信支付和加密货币。国内用户下单时用常用网络注册，别挂代理，否则可能触发人工审核拖慢开通。

**口碑**方面，RackNerd 连续三年在 LowEndTalk 平台被票选为 TOP1–TOP3 商家，中文客服长期活跃在社交平台；CloudCone 只能英文沟通，售后响应 30 分钟到数小时，在海外商家里属于正常水平。Trustpilot 上对 RackNerd 的好评集中在价格低、客服响应快，吐槽集中在晚高峰国内速度波动和特价套餐不退款——这几条和前面写的一致，倒也坦诚。

## 按用途选：一张决策清单

照着用途对号入座就行：

- 学 Linux、跑脚本、挂节点、搭临时测试环境，宕机一天没损失 → RackNerd 1GB 或 2GB 年付套餐，一年一杯奶茶钱
- 想折腾 AI 应用（Ollama、AnythingLLM）→ RackNerd 4GB 起步，或者直接看它的 Ryzen NVMe 系列
- 建站、外贸、跑正式程序，需要快照和备份兜底 → CloudCone 的 SC2 线更合适，自动备份是内置的
- 业务负载忽高忽低、要频繁开关实例 → CloudCone 的按小时计费模式，RackNerd 的年付制不适合这种用法
- 主要服务国内用户且对延迟敏感 → 说实话这两家都不是最优解，CN2 GIA 线路的商家（比如搬瓦工、DMIT）更对口，只是价格完全是另一个档位

## 常见问题

**RackNerd 还有 $11.29/年 的套餐吗？**
没有了。那是新年促销的存量套餐，已下架，目前官网特价起步价 $21.99/年。看到还在推 $11.29 的文章直接跳过，价格信息已经过期。

**RackNerd 支持退款吗？**
不支持，特价套餐明确不退款。下单前用它的测速 IP 确认线路，付款后 72 小时内 IP 有问题可免费换一次。

**CloudCone 的按小时计费是什么意思？**
按实例实际运行的小时数扣费，随时创建、随时销毁，适合短期测试和间歇性负载。跑长期稳定业务的话，年付套餐划算得多。

**两家可以都用优惠码省钱吗？**
RackNerd 的 VPS 特价不需要优惠码，走特价链接就是优惠价，官方有效码只针对独立服务器（如独服终身 85 折的 15OFFDEDI）；CloudCone 的优惠跟着活动走，没有常设 VPS 优惠码。
